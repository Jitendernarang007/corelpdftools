Privacy

  • Files you upload are processed automatically to make a CorelDRAW-compatible copy.
  • Your original file is deleted as soon as processing finishes. The fixed file and its previews are deleted within 1 hour.
  • We do not look at, share, sell or reuse your files.
  • If you click “Did it open?”, we store your answer and the CorelDRAW version you picked, linked only to a random job number.
  • We count how many files each internet address fixes per day to enforce the free limit. This count is kept in memory only and is not stored.
  • We keep simple usage counts (number of files fixed or failed, page counts, the CorelDRAW version picked) to improve the tool. These contain no files, file names or personal details.
  • Visitor statistics are collected with GoatCounter, which uses no cookies and does not track you across websites.

Questions: support@corelpdftools.com
